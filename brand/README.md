# Mint Statements brand files

| File | Use it for |
|---|---|
| `mint-statements-icon.svg` / `-512.png` / `-1024.png` | App-style square icon (Stripe branding icon, Canva, documents) |
| `mint-statements-icon-round.svg` | Round version for circular spots |
| `instagram-profile-1080.png` | Instagram / social profile picture (crops to a circle) |
| `mint-statements-logo.svg` / `.png` | Icon + name, for light backgrounds |
| `mint-statements-logo-white.svg` / `.png` | Icon + name, for dark backgrounds |

Colors: deep green `#0b5d4b`, mint `#2fd3a0`, light mint `#b9f3dd`, ink `#0d1c17`, gold `#f5c451`.
Font: Bricolage Grotesque ExtraBold (SIL Open Font License; in `public/fonts`). The name in the logo files is already converted to shapes, so no font is needed to use them.
